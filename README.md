# ProjectDawn

던전앤파이터의 바칼 레이드를 소재로 만든 1~4인 협동 액션 프로젝트입니다. Unity 클라이언트와 C# 서버로 구성했으며, 개인 학습 프로젝트로 판매하거나 배포하지 않습니다.

방장 클라이언트가 Lua로 패턴과 행동을 제안하면 서버의 C# 공통 코어가 검증합니다. 입력을 기록해 두었다가 확정 결과로 다시 판정해, 연출은 즉시 보여주면서 결과는 서버가 결정합니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `Packages/com.projectdawn.combat` | 서버와 클라이언트가 공유하는 전투 코어 |
| `Server/ServerCore` | TCP·UDP 네트워크 기반 |
| `Server/Server` | 로그인, 매칭, 방, 레이드 검증, 보상 저장(MySQL), 모니터링 |
| `Server/PacketGenerator` | 패킷 처리 코드 생성기 |
| `CloudGateway` | 외부 접속 중계와 회원 계정 |
| `Client`, `UnityClient` | 네트워크 클라이언트와 Unity 표시 코드 |
| `Lua`, `Protocol` | 보스 패턴 스크립트와 메시지 정의 |

## 참고

- 소스 코드만 공개합니다. 리소스, 도구, 테스트, 생성된 패킷 코드, 배포 설정은 포함하지 않아 이 저장소만으로는 빌드되지 않습니다.
